🚀 CLI & Startup Flags p.1

⚡ Launch Modes
claudeStart interactieve terminal sessie
claude "prompt"Start en voer direct instructie uit
claude -p "query"Print mode — streamt en sluit af (pipes)
claude -cHervat meest recente conversatie
claude -r <id>Hervat specifieke sessie op ID
🛠️ Optimalisatie Flags
--no-thinkingZet deep thinking uit (sneller, minder tokens)
--thinkingForceer analytisch denken voor complexe taken
--model <naam>Specificeer model bij opstarten
-w <tree>Start in geïsoleerde Git worktree
--verboseStream systeemprompts + token counts
--versionToon exacte build-versie
🎛️ Account & Config
claude login/logoutAuthenticeer of wis sessie
claude configOpen configuratiemanager
claude config set <k> <v>Wijzig instelling direct
claude config get <k>Lees actieve waarde
